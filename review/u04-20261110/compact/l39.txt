語素以 + 連接，詞組以 / 分開。

D1
d1.t01 annie｜저기요, 제 휴대폰 좀 봐 주세요.
저기요 / 저+의 / 휴대폰 / 좀 / 보다+아 / 주다+세요
不好意思，請幫我看一下我的手機。
d1.t02 guesthouse_clerk｜네, 어떤 문제가 있어요?
네 / 어떤 / 문제+가 / 있다+어요
好的，請問有什麼問題嗎？
d1.t03 annie｜화면이 안 나와요.
화면+이 / 안 / 나오다+아요
螢幕沒有畫面。
d1.t04 guesthouse_clerk｜이 휴대폰이요? 화면이 까맣네요.
이 / 휴대폰+요 / 화면+이 / 까맣다+네요
是這支手機嗎？螢幕是黑的呢。
d1.t05 annie｜네, 맞아요.
네 / 맞다+아요
對，沒錯。

D2
d2.t01 michael｜저기요, 저 태블릿이 안 켜져요.
저기요 / 저 / 태블릿+이 / 안 / 켜지다+어요
不好意思，那台平板開不了機。
d2.t02 guesthouse_clerk｜창가에 있는 태블릿 말씀이세요?
창가+에 / 있다+는 / 태블릿 / 말씀+이다+세요
您是指窗邊的那台平板嗎？
d2.t03 michael｜네, 저거예요.
네 / 저것+이다+에요
對，就是那台。
d2.t04 guesthouse_clerk｜네, 알겠어요. 저 태블릿이 안 켜지는 거군요.
네 / 알다+겠+어요 / 저 / 태블릿+이 / 안 / 켜지다+는 / 것+이다+군요
好的，我知道了。是那台平板開不了機啊。
